# 사용방법서

감정평가 지도 사진자료(광역위치도·상세위치도·지적도 + 3페이지 Word)를 주소만 넣어서 만드는 방법입니다.
AI(Claude, Codex 등)에게 시킬 때와 직접 실행할 때 모두 설명합니다.

## 1. 무엇이 만들어지나

| 파일 | 내용 | 지도 출처 |
|---|---|---|
| `…_광역위치도.jpg` | 물건지 중심 스카이뷰, 물건지 경계 빨강 + "본건위치" | 카카오맵 스카이뷰 (실제 캡처) |
| `…_상세위치도.jpg` | 물건지(빨강)·비교표준지(파랑)·평가사례(주황) 함께 표기 | 경기부동산포털 (실제 캡처) |
| `…_지적도.jpg` | 물건지 경계와 지번이 보이는 연속지적도 | 경기부동산포털 (실제 캡처) |
| `<물건지 주소>.docx` | 위 3장을 1페이지 1장씩 배치한 Word 3페이지 | — |
| `metadata.json`, `경기부동산포털_캡처_메모.txt` | 입력 주소·출처·경고 기록 | — |

색 약속: **물건지 빨강 / 비교표준지 파랑 / 평가사례 주황 / 거래사례 초록**.

> 경기도 내 필지만 지원합니다(경기부동산포털 기준). 도식·가짜 지도는 만들지 않고, 실제 캡처가 실패하면 실패로 처리합니다.

## 2. 설치

> **Windows 사용자:** 아래 macOS/Linux 명령 대신 `run_windows.bat`을 더블클릭하면 설치와 웹 화면 실행이 한 번에 됩니다. 명령행에서는 `./.venv/bin/python`을 `.venv\Scripts\python`으로 바꿔 쓰면 됩니다(한 줄로 입력). Chrome이 없으면 Edge를 대신 사용하고, 설치 위치가 특이하면 환경변수 `CHROME_PATH`에 실행 파일 경로를 지정하세요.

필요한 것: Python 3.10 이상, Google Chrome(헤드리스로 자동 실행됩니다), macOS 또는 Windows.

```bash
git clone https://github.com/haho240414/gamjeong-map-photo.git
cd gamjeong-map-photo
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt      # Windows: .venv\Scripts\pip
```

- macOS는 `감정평가위치도.command`를 더블클릭하면 설치부터 웹 화면 실행까지 자동으로 합니다.
- API 키는 필요 없습니다(`.env.example` 참고, 있으면 보조 조회에만 쓰입니다). `.env`는 올리지 마세요.

## 3. 가장 쉬운 방법: AI에게 시키기

이 저장소를 연 Claude/Codex에게 아래처럼 말하면, 저장소의 `AGENTS.md`(`CLAUDE.md`)를 읽고 같은 방식으로 작업합니다.

```text
이 저장소의 지침대로 감정평가 지도 사진자료를 만들어줘.

물건지: 경기도 양주시 덕정동 366-12
비교표준지: 덕정동 190-5
평가사례지: 덕정동 138-14, 138-88, 138-37

완성한 Word 문서와 JPG 3장을 전달하고, 필지 누락 여부를 확인해서 알려줘.
```

입력 규칙:

- **물건지가 여러 필지**면 쉼표로: `경기도 양주시 덕정동 100-1, 100-2, 100-3`
- **같은 리·동은 앞에만 전체 주소**, 나머지는 지번만 써도 됩니다.
- **비교표준지가 여러 개**면 각각 적습니다(표기: 비교표준지1, 2…).
- **평가사례지**: 쉼표로 묶은 필지는 **한 건**(라벨 하나)으로, `/` 또는 줄을 나누면 **서로 다른 사례**(평가사례1, 2…)로 표기합니다.
- 산(임야)은 `산 22-5` 또는 `산-22-5`.

### 채무자 기존토지 + 신규 매입지

```text
기존토지(채무자): 경기도 양주시 덕정동 100-1, 100-2
신규 매입지: 덕정동 101-1, 102
기존토지는 빨강, 신규 매입지는 주황으로 광역·상세·지적도 모두 표기해줘.
```

## 4. 직접 실행하기 (명령행)

```bash
./.venv/bin/python map_photo_prototype.py \
  --subject-address "경기도 양주시 덕정동 366-12" \
  --standard-address "경기도 양주시 덕정동 190-5" \
  --case-address "경기도 양주시 덕정동 138-14, 138-88, 138-37" \
  --capture-portal --skip-trades \
  --appraisal-no "사건번호" \
  --output-dir ./outputs
```

| 옵션 | 설명 |
|---|---|
| `--subject-address` | 물건지(쉼표로 여러 필지) |
| `--standard-address` | 비교표준지(여러 번 사용 가능) |
| `--case-address` | 평가사례지(여러 번 사용 가능, 한 번 안의 쉼표 나열은 한 건) |
| `--existing-new` | 기존토지(`--subject-address`)와 신규 매입지(`--case-address`)를 함께 표기하는 모드 |
| `--capture-portal` | 실제 지도 캡처 사용(**항상 권장**) |
| `--skip-trades` | 거래사례 자동 표기 생략 |
| `--output-dir` | JPG·메모 출력 폴더 (기본 `outputs`) |
| `--word-output-dir` | Word 저장 폴더 (환경변수 `MAP_PHOTO_WORD_DIR`로도 지정) |
| `--appraisal-no` | 사진자료 상단에 쓸 번호 |
| `--office-name` | 하단 사무소명 |
| `--extra-detail` | Word 4쪽 이후에 덧붙일 상세지도 `이미지경로\|캡션`(여러 번 가능). 사례가 멀 때 본건·비교표준지 확대도를 4쪽으로 붙이는 데 쓴다 |
| `--chrome-path` | Chrome 실행 파일 경로(자동 탐색 실패 시) |

웹 입력 화면을 쓰려면 `./.venv/bin/python webapp_server.py --open` (주소 `http://127.0.0.1:8877`).

### 한글 서식(위치도·건물개황도) 만들기

`form_documents.py`가 `34-580 위치도`와 `34-581 건물개황도` 한글 서식의 칸 치수를 그대로 본떠 Word로 만듭니다(`build_location_form`, `build_building_form`). 건물개황도의 도면 칸 그림은 `building_sketch.py`로 층별 외곽과 치수선을 그립니다.
면적·용도·구조는 **건축물대장 값**으로 채우세요. 스캔된 건축물현황도 치수로 계산한 값은 대장과 3~5% 어긋날 수 있습니다.

## 4-1. 걸리는 시간·재시도

경기부동산포털이 느리면 1~5분 걸리고, 지도 준비 시간 초과로 **실패할 수 있습니다.** 실패하면 경고에
`경기부동산포털 자동 캡처 실패`가 나오고 도식 지도가 대신 만들어집니다. **그 결과는 쓰지 말고 같은 명령을 다시 실행하세요.**

## 5. 결과 확인 체크리스트

1. `outputs/photo_material_…/portal_capture/portal_raw_detail.json` 의 `found` 개수가 입력 필지 수와 같고 `missing`이 비어 있는가.
2. 광역위치도에 빨간 경계와 "본건위치"가 보이는가(50m 눈금, 반경 약 500m).
3. 상세위치도에 입력한 모든 필지가 색깔대로 표시되고, 라벨이 해당 필지 옆에 있는가.
4. 지적도에서 물건지 경계와 지번이 선명한가.
5. Word가 3페이지이고 이미지가 잘리지 않았는가(PDF로 열어 확인).

## 6. 자주 겪는 문제

- **(Windows) 글자가 깨져 보임:** 콘솔은 자동으로 UTF-8로 맞춥니다. 그래도 깨지면 `chcp 65001` 후 실행하세요. 한글 폰트는 맑은 고딕을 씁니다.
- **(Windows) `.ps1`이 막힘:** `run_windows.bat`을 쓰거나, PowerShell에서 `Set-ExecutionPolicy -Scope Process Bypass` 후 실행하세요.
- **(Windows) 캡처가 시작되지 않음:** 백신/보안 프로그램이 헤드리스 Chrome을 막는 경우가 있습니다. `CHROME_PATH`가 올바른지, Chrome이 최신인지 확인하세요.

| 증상 | 원인 / 해결 |
|---|---|
| `지원하지 않는 법정동/리 주소입니다` | 해당 리의 코드가 `DONG_MAP`에 없음 → `AGENTS.md` §6 방법으로 코드를 찾아 추가 |
| 입력한 필지가 `missing` | 지번이 지적도에 없음(합병·분할·오기). 정확한 지번 확인 후 재실행. 없는 필지를 임의로 그리지 않음 |
| 광역위치도 배경이 흐림 | 산지·농지는 스카이뷰 원본 해상도가 낮음(카카오맵 자체 한계) |
| 참고 필지가 멀어 물건지가 작게 보임 | 상세위치도는 모든 필지가 들어가게 맞춤 → 가까운 필지만 쓰거나 지도를 나누어 생성 |
| 카카오맵 캡처 실패 | 카카오맵 UI 변경 가능성 → `kakao_capture_chrome.py`의 셀렉터 확인 |
